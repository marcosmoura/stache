# 05 — Frame effects and core runtime lifecycle

Read when implementing after 04, after Bar foundation has merged and this branch has rebased onto it, and separate approval. Factory is compiled/inert but not production-registered until 06; no incomplete public command success.

## Scope

Tiling `src/{runtime.rs,module.rs,effects/,outcome.rs,reservations.rs}`; app `host.rs` factory/context and fake composition tests. Reuse landed accepted-watch/factory begin-shutdown/finish and host reservation observation hooks; no parallel lifecycle. Map legacy init/subscriber/executor/cache/window_ops in inventory. Reservations are consumed before the first frame effect, not deferred to 10 or production registration in 06.

## Requirements

- `configure` validates/prepares pure plans, construction is inert. `start` stages observers/actor/effect resources with exact rollback, queues initial enumeration before Running and returns without waiting for all window moves. Missing AX → WaitingForPermission; core infrastructure failure → appropriate Unavailable/Failed. Reuse landed shared input modules' user-request-only permission metadata/policy: status checks never prompt and only explicit host tray requests may prompt; no Tiling-specific prompt or automatic permission changes. Individual resize refusal is operation degradation, not asynchronous registry Failed. Optional feature capability absence is explicit; no false healthy claim.
- Pure deltas track desired versus **confirmed actual** frames and monotonically changing layout plan sequence (A→B→A distinct). Frame executor sends only changed eligible frames; outcomes return to actor tagged by exact window/generation/revision/plan. Acknowledging an old plan cannot clean a new plan. Readback mismatch/refusal/partial size-position records actual frame and unresolved components; never mark desired frame applied on enqueue or a partial setter.
- Subscribe-before-fetch to landed host reservation snapshots using native typed DisplayId, topology generation, exact reservation owner/generation and monotonic sequence. Normalize reservations measured inward from full display logical bounds: derive native insets from visibleFrame, take per-edge max(native inset, host aggregated reservation), then add own tiling outer gap exactly once. Upstream same-edge max is not a sum; full top0/native24/reservation40/own6 gives top46, not70. Use one logical coordinate space at scales1/2 and negative origins; invalid/nonfinite/infeasible geometry yields explicit no-frame diagnostic, never fabricated safe space. No Bar config reads. Missing active reservations means zero host inset, not loss of native exclusion; incomplete/stale topology cannot authorize a write to a reused display. Snapshot/tombstone changes invalidate plans atomically before deferred recompute; actual send still checks accepted revision, runtime/token/topology/plan authority. Stale fetch/releases cannot overwrite successors. Stop cancels/wakes/unsubscribes with existing lifecycle ownership; failed cleanup stays retained. Part 10 adds final cross-module tests, not this first safety seam.
- Per window/plan, issue each required position/size component at most once, with one bounded readback; retain unsupported/refused capability diagnostics. Only an explicit new user command or meaningful external/config/topology change may create a new attempt, not repeated own AX echoes/periodic refresh. No immediate retry loop or fighting unresizable apps. Minimum-size inference is bounded and reset by balance/new evidence, not infinite enlargement.
- Reconfigure stages fallible pure/resource changes then consumes the landed typed accepted-config publication described by the canonical contract (accepted typed value plus actual revision published as one coherent cell before notification; module flips staged resources only after observing that same revision through a bounded cancellation-wakeable watch; no module-local revision counters, no `revision + 1`, no callback under the publication lock). If that contract is still absent, block rather than owning a second publisher or guessing. No candidate effects before acceptance, no native work under accepted publication lock. Rejection keeps runtime/publication/authority unchanged. Accepted updates preserve compatible user layout/ratios/floating/focus; structural policy is defined by 06. Physical writes after acceptance can fail/partially apply and cannot roll back transactionally: publish typed actual outcomes without pretending configuration rejection undoes them.
- Internal operation outcome has Enqueued, Applied, Partial, Uncertain plus typed failed/not-attempted/stale reasons and per-target/component evidence. Enqueued means actor admission only; Applied requires confirmation of stated scope, not all unrelated desktop windows. Reuse actual-send permits from 03, plan deadlines and current authority for every native component.
- Stop linearizes atomic seal/invalidation before any stalled commit wait; publish unavailable/tombstone immediately. Cancel/wake admission, enumeration, timers and all host handler waits before IPC joins. Drain outstanding frame/animation issuance (08 extends same seam), then 06-owned restore/unhide, then native observer removal/owner cleanup, actor close and worker joins off-main. Registry may already cancel before stop; cleanup uses fresh finite 2 s per-hop waits, not the cancelled work token.
- Preserve owner dispatch until reverse registry stop and factory finish/drain. In-flight native calls are irreversible; finite acknowledgement timeout is not a hard OS interruption guarantee or global shutdown SLA. Failed stage cleanup retains inert exact resources/progress/error state in quarantine, no restart until cleaned; retries do not duplicate already completed stages. No detached worker used to hide blocked joins.
- Host read-only status overlays ConfigStore held parse/type/I/O/deletion diagnostics without disk access; repaired file clears it independently of operation/native cleanup errors. Independent modules continue if Tiling fails/stops. Production registration remains gated until workspace-safe 06, not enabled early to demonstrate frames.
